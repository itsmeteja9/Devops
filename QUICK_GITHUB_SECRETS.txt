                    GITHUB SECRETS - QUICK ADD GUIDE
═══════════════════════════════════════════════════════════════════════════════

📍 WHERE TO ADD:
  Repository → Settings → Secrets and variables → Actions

═══════════════════════════════════════════════════════════════════════════════

🔴 REQUIRED - Must Add:

1. GCP_SA_KEY
   ├─ Get from: GCP Service Account JSON key file
   ├─ Command: gcloud iam service-accounts keys create key.json --iam-account=github-actions@devops-504816.iam.gserviceaccount.com
   └─ Action: Paste entire JSON contents


🟡 OPTIONAL - Add if needed:

2. SONAR_TOKEN (for code quality scanning)
   ├─ Get from: https://sonarcloud.io/account/security
   └─ Action: Generate token and paste value

3. SONAR_HOST_URL (only if self-hosted SonarQube)
   ├─ Value: https://your-sonarqube-instance.com
   └─ Action: Paste your SonarQube URL

4. DD_API_KEY (for Datadog monitoring)
   ├─ Get from: https://app.datadoghq.com/organization/settings/api-keys
   └─ Action: Generate key and paste value

═══════════════════════════════════════════════════════════════════════════════

📋 OPTIONAL - Variables (NOT Secrets):

5. DD_SITE (Variable - not secret!)
   ├─ Value: datadoghq.com (or datadogheu.com for EU)
   └─ Action: Type value in Variables section

═══════════════════════════════════════════════════════════════════════════════

✅ VERIFY:
  1. Go to Settings → Secrets and variables → Actions
  2. Check GCP_SA_KEY is listed with ✓ symbol
  3. Other secrets optional - pipeline handles gracefully if missing
